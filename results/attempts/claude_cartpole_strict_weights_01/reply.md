I wrote this as a linear state-feedback controller, assuming the system is a cart-pole: obs = [cart position, pole angle, cart velocity, pole angular velocity]. I couldn't run or test it, so the gains are an educated guess.

The control law is u ≈ 0.5·x + 10·θ + 0.7·ẋ + 1.5·θ̇. One hidden unit computes tanh(0.1·z) and the output weight of 10 undoes the 0.1 scaling, so the network is nearly linear over the expected range. The other 15 hidden units have zero weights and contribute nothing.
