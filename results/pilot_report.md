# Report (local, not for git)

Simulation only (MuJoCo via Gymnasium). Score = mean return over 100 episodes, reset seeds 10000..10099.
Every attempt is listed, failures (unparsable/invalid replies) included and counted as failures, not dropped.
`full` = attempts whose mean return is >= 900. On hopper a return near 1000 can mean standing without falling for 1000 steps (reward is 1/step alive + forward speed): see the distance columns. For hopper, the per-attempt cells read `return/forward-distance`; hopper `success` = mean forward distance >= 1 m over the 100 scoring episodes (owner decision 2026-11-06, applied to every hopper arm, old and new). Forward speed = distance / (mean steps x 0.008 s).
Attempts labelled `contaminated: /tmp/CLAUDE.md` in their meta (round-2 Sonnet controller and Opus runs that had an unrelated project file loaded) are excluded from every table below and listed in their own section at the end. Their isolated reruns have ids ending `_iso2`. The hopper `goal` arm is the strict prompt plus one sentence naming forward distance as the goal.
